## 📄 T-Coin 区块链挖掘模拟器 使用说明 (v0.1.1)

### 🚀 简介

T-Coin 挖掘模拟器是一个基于 Python 和 Tkinter 的桌面应用程序，旨在帮助用户直观地理解**工作量证明 (Proof-of-Work)** 区块链的运作原理，包括交易签名、挖矿过程、难度调整和链条验证。

**版本号：** `0.1.1`
**作者：** AnonUSAl
**开源地址：** [GitHub 仓库](https://www.google.com/search?q=https://github.com/AnonUsAl)

### 🛠️ 安装与运行

#### 1\. 环境要求

  * **操作系统：** Windows / macOS / Linux
  * **Python 版本：** 3.x
  * **依赖库：** `hashlib` (标准库)、`json` (标准库)、`tkinter` (标准库)、`easygui`

#### 2\. 安装依赖

请确保您的环境中已安装 `easygui` 库。其他库均为 Python 标准库，无需额外安装。

```bash
pip install easygui
```

#### 3\. 启动程序

将程序代码保存为 `.py` 文件（例如 `tcoin_miner.py`），然后通过命令行运行：

```bash
python tcoin_miner.py
```

如果这是您第一次运行，程序将提示您**创建创世区块**，并自动生成 `improved_tcoin_chain.json` 文件用于数据持久化。

### 核心功能操作指南

程序界面分为**控制区（左侧）和显示区（右侧）**。

#### 1\. 钱包与身份管理

| 操作 | 目的 | 步骤 |
| :--- | :--- | :--- |
| **切换/创建钱包** | 更改当前挖矿或发送交易的身份。 | 在“当前矿工/发送方”输入框中输入新名字，点击 **“切换/创建钱包”**。如果钱包不存在，程序会自动为其生成地址和私钥。 |
| **查看余额** | 实时计算当前钱包的 T 币余额。 | 查看主界面右下方状态栏，或切换到 **“账户余额”** Tab。 |

#### 2\. 创建交易

所有用户间的 T 币转移都需要经过签名并添加到待处理列表，等待矿工打包。

1.  在 **“创建交易”** 区输入 **接收方钱包名** 和 **金额**。
2.  点击 **“提交交易 (签名)”**。程序将使用您当前身份的私钥进行模拟签名。
3.  如果余额足够且签名成功，交易将进入**待处理交易**列表。

> ⚠️ **注意：** 交易成功提交后，您需要通过挖矿才能将此交易正式记录到区块链上。

#### 3\. 挖矿操作 (PoW)

挖矿是将待处理交易打包成新区块并获得奖励的过程。

| 模式 | 描述 | 按钮 |
| :--- | :--- | :--- |
| **单次挖矿** | 执行一次完整的工作量证明计算。挖矿成功后会弹出提示。 | **⛏ 单次挖矿 (PoW)** |
| **持续挖矿** | 自动重复执行挖矿过程，直到发现新区块。适合在后台运行。 | **🚀 开始持续挖矿** / **🛑 停止持续挖矿** |

  * **难度：** 当前挖矿难度显示在“核心操作”区，它决定了找到正确 Proof (Nonce) 所需的工作量。难度会随着链条的增长而动态调整。
  * **奖励：** 成功挖矿的矿工将获得 `5 T 币` 的系统奖励。

#### 4\. 数据与验证

| 操作 | 目的 | 说明 |
| :--- | :--- | :--- |
| **保存区块链** | 将当前的区块链状态保存到 `improved_tcoin_chain.json` 文件。 | **保存区块链 (.json)** |
| **加载区块链** | 从 `improved_tcoin_chain.json` 文件中加载历史数据。 | **加载区块链 (.json)** |
| **验证完整性** | 从头到尾检查每个区块的 `previous_hash` 和 `Proof of Work` 是否有效。 | **验证区块链完整性** |

### 🔍 数据显示区 (Tab 页)

右侧 Notebook 区域提供了区块链数据的可视化视图：

| Tab 页 | 显示内容 | 特点 |
| :--- | :--- | :--- |
| **完整区块链** | 链上所有区块的详细信息，包括哈希、时间戳、Proof 和交易列表。 | **倒序显示**（最新区块在顶部）。通过颜色高亮显示哈希有效性。 |
| **账户余额** | 所有参与过交易的用户的实时 T 币余额。 | 余额基于交易历史计算。 |
| **待处理交易** | 等待被矿工打包到下一个区块中的交易列表。 | 每次成功挖矿后，此列表将被清空。 |
